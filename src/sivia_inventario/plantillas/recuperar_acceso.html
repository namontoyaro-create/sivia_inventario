Identificar mi usuario localmente

En la terminal de VS Code, dentro del proyecto, ejecuta:

poetry run python -m sivia_inventario.generar_codigo_recuperacion --identificar-administrador

La consola pedirá confirmar IDENTIFICAR tu_usuario. Solo si existe una única cuenta administradora activa mostrará ese usuario localmente. No muestra otras cuentas en la web.

Restablecer contraseña

Genera el código temporal desde VS Code con --administrador. El código identifica la cuenta autorizada, por lo que no necesitas escribir el usuario aquí.
